# Coffee Shop Sales Analysis Dashboard | Excel

## Project Overview
This project analyzes coffee shop transaction data using Microsoft Excel to understand sales performance, product demand, customer ordering patterns, and store-level trends.

The interactive dashboard presents key business metrics and visualizations to support data-driven decision-making.

## Business Objectives
- Analyze overall sales performance.
- Identify peak sales hours and ordering patterns.
- Compare sales across product categories and product types.
- Understand order-size distribution.
- Compare performance across store locations.
- Identify opportunities to improve sales and operations.

## Dataset Description
The dataset contains 149,116 transaction records and 18 columns.

Key fields include:
- Transaction ID, date, and time
- Store ID and store location
- Product category, type, and details
- Transaction quantity and unit price
- Total bill
- Month name, day name, and hour

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design
- Data Analysis and Visualization

## Key Performance Indicators (KPIs)
- Total Sales: $698,812.33
- Transaction Records: 149,116
- Average Bill per Transaction: Approximately $4.69
- Average Quantity per Transaction: Approximately 1.44

Note: KPI definitions should be validated against the workbook's formulas before interpreting them as customer footfall or unique customer counts.

## Dashboard Features
1. Hourly quantity and ordering trends
2. Sales distribution by product category
3. Order-size distribution
4. Top product types by sales
5. Store-level sales comparison
6. Orders by day of the week
7. Month and day filters for interactive analysis

## Analysis Approach
1. Reviewed the dataset structure and fields.
2. Examined transaction dates, product details, quantities, and sales values.
3. Used Excel Pivot Tables to summarize data.
4. Created charts to compare sales and ordering patterns.
5. Combined the visualizations into an interactive dashboard.

## Business Insights
- Hourly analysis helps identify periods of higher and lower order quantities.
- Product-level comparisons highlight products that contribute substantially to sales.
- Category and size distributions help explain the composition of orders.
- Store comparisons can help identify differences in sales performance.
- Weekday analysis helps compare demand across the week.

## Business Recommendations
- Align staff scheduling and inventory planning with observed peak hours.
- Review high-performing products to identify opportunities for promotions and cross-selling.
- Investigate low-performing products before making pricing or assortment changes.
- Compare store-level performance to identify practices that may be replicated.
- Monitor monthly and weekday trends to support demand planning.

## Project Files
- `Coffe_shop_sales.xlsx` — Excel workbook containing the dashboard and Pivot Table analysis.
- `dashboard.png` — Screenshot of the dashboard.
- `data/` — Dataset files, if included.

## Future Improvements
- Perform deeper analysis using SQL.
- Create a Python-based exploratory data analysis notebook.
- Develop an interactive Power BI dashboard.
- Add month-over-month growth, product contribution, and other validated business KPIs.

## Conclusion
This project demonstrates practical Excel-based data analysis, KPI reporting, data visualization, and business-oriented interpretation of retail transaction data.
